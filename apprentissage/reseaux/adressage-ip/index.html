Comprendre l’adressage IP et les bases réseau.

Cette fiche donne les repères indispensables pour lire une configuration réseau simple : modèles OSI/TCP-IP, adresse IPv4, masque, passerelle, DNS et premiers tests de connectivité.

Durée : 20 min Niveau : débutant Sujet : IPv4

1. Deux modèles pour se repérer

Un réseau peut être vu comme une pile de responsabilités. Le modèle OSI aide à raisonner couche par couche, tandis que TCP/IP correspond davantage à la réalité des réseaux modernes.

OSI TCP/IP Question à se poser
Physique / Liaison Accès réseau Le câble, le Wi-Fi ou la carte réseau fonctionnent-ils ?
Réseau Internet L’adresse IP, le masque et la passerelle sont-ils cohérents ?
Transport Transport Le service utilise-t-il TCP ou UDP ? Le port est-il joignable ?
Session à Application Application Le service applicatif répond-il correctement ?

2. Lire une adresse IPv4

Une adresse IPv4 identifie une machine dans un réseau. Elle est accompagnée d’un masque, qui sépare la partie réseau de la partie hôte. 

Exemple :
Adresse IP  : 192.168.1.25
Masque      : 255.255.255.0  (/24)
Réseau      : 192.168.1.0
Hôte        : 25
Passerelle  : 192.168.1.1

Ici, toutes les machines en 192.168.1.x avec le masque /24 sont dans le même réseau local. La passerelle sert à sortir vers d’autres réseaux, par exemple Internet.

3. Diagnostiquer dans le bon ordre

Quand la connexion ne fonctionne pas, il faut éviter de tester au hasard. Une méthode simple consiste à remonter progressivement depuis la machine locale vers Internet.

1. Carte réseau 2. Passerelle 3. DNS 4. Service final 
# Vérifier la configuration IP
ipconfig        # Windows
ip addr         # Linux

# Tester la passerelle
ping 192.168.1.1

# Tester Internet sans DNS
ping 8.8.8.8

# Tester la résolution DNS
nslookup tiansemi.github.io

4. Exercice rapide

Une machine a l’adresse 192.168.10.34/24. Répondez mentalement :

  1. Quel est le réseau ?
  2. Quelle pourrait être une passerelle logique ?
  3. Une machine 192.168.11.8/24 est-elle dans le même réseau ?

Réponses attendues : réseau 192.168.10.0, passerelle possible 192.168.10.1, et non, 192.168.11.8/24 est dans un autre réseau.

À retenir

  • L’IP identifie une machine.
  • Le masque indique la taille du réseau.
  • La passerelle relie à d’autres réseaux.
  • Le DNS transforme un nom en adresse IP.
