Filière Cybersécurité · Fiche débutant

Reconnaître les attaques courantes et réagir correctement.

Cette fiche introduit les menaces les plus fréquentes pour un étudiant ou un jeune professionnel : phishing, mots de passe faibles, malwares, faux liens et mauvaises configurations.

Durée : 20 min Niveau : débutant Sujet : hygiène sécurité

1. Les attaques à connaître en premier

Attaque Principe Signal d’alerte
Phishing Faire croire à un message légitime pour voler un mot de passe ou pousser au clic. Urgence artificielle, faute de domaine, pièce jointe inattendue.
Mot de passe faible Deviner ou réutiliser un mot de passe déjà compromis. Même mot de passe partout, absence de MFA.
Malware Installer un programme malveillant via fichier, lien ou logiciel piraté. Fichier étrange, demande d’exécution, antivirus désactivé.
Mauvaise configuration Exposer involontairement un service, un dépôt ou une donnée sensible. Accès public non prévu, secret visible, permissions trop larges.

2. Lire un message suspect

Un bon réflexe consiste à vérifier l’expéditeur, le domaine du lien, le contexte et la demande réelle. Un message peut utiliser un logo officiel tout en pointant vers une adresse frauduleuse. 

Exemple de vérification :
1. L’adresse de l’expéditeur correspond-elle au service attendu ?
2. Le lien pointe-t-il vers le vrai domaine ?
3. Le message crée-t-il une urgence inhabituelle ?
4. La pièce jointe était-elle attendue ?
5. Puis-je confirmer par un autre canal ?

3. Les premiers réflexes de protection

  • Utiliser un mot de passe unique par service, idéalement généré par un gestionnaire de mots de passe.
  • Activer l’authentification multifacteur dès qu’elle est disponible.
  • Mettre à jour le système, le navigateur et les applications critiques.
  • Éviter les logiciels piratés et les pièces jointes non attendues.
  • Sauvegarder les données importantes hors de la machine principale.

4. Si vous avez cliqué

L’objectif n’est pas de paniquer, mais de réduire vite l’impact. Déconnectez la session suspecte, changez le mot de passe depuis un appareil sain, activez la MFA et signalez l’incident à une personne compétente.

1. Isoler 2. Changer 3. Vérifier 4. Signaler

À retenir

  • Le phishing joue sur l’urgence et la confiance.
  • Un mot de passe réutilisé devient un risque global.
  • La MFA bloque de nombreuses compromissions.
  • Signaler vite vaut mieux que cacher l’incident.
